# Lärpuls

Lär lite, varje dag. Lärpuls är en svenskspråkig, mobilförst mikrolärandeapp med snabba lärkort, fördjupningar, quiz, ämnesfilter och lokal framstegsspårning.

## Kom igång

```sh
npm install
npm run dev
```

Öppna adressen som Vite skriver ut i terminalen. För en produktionsbyggnad:

```sh
npm run build
npm run preview
```

## Installera på mobilen

Lärpuls är en progressiv webbapp (PWA) och fungerar i moderna Android- och iOS-webbläsare.

- **Android:** öppna appen i Chrome och välj **Installera app** eller **Lägg till på startskärmen** i webbläsarmenyn.
- **iPhone/iPad:** öppna appen i Safari, tryck på **Dela** och välj **Lägg till på hemskärmen**.
- Installationsfunktionen kräver HTTPS när appen publiceras. `localhost` fungerar för lokal utveckling.

Appens innehåll och gränssnitt kan användas offline efter att appen har laddats en gång. Framsteg, sparade kort, XP och quizbonusar lagras lokalt i webbläsaren på enheten. De synkas inte mellan enheter.

## Det här finns i appen

- 20 ämnesområden och 10 030 svenska mikrolektioner. Biblioteket innehåller 30 handskrivna startlektioner och 10 000 nya övningsbaserade kort: 200 ämnesspecifika lärandemål i 50 praktiska övningsformat.
- Tre korta insikter per lärstund, med möjlighet att gå vidare till fördjupning, praktisk övning och kunskapsquiz.
- Spela korta eller fördjupade lektioner som talupplästa videoöversikter, eller hämta ett NotebookLM-underlag för att skapa en AI-genererad Video Overview.
- Sökning, ämnesfilter, sidindelning, bokmärken, dagligt mål, XP, nivåer, streaks, märken och veckovy.
- Källor och försiktighetsnotiser för innehåll om hälsa och privatekonomi.

Lärpuls ger allmän utbildning, inte individuell vård, diagnos eller finansiell rådgivning. Läs mer via källorna i respektive lärstund och sök professionell hjälp när det behövs.
